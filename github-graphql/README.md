# GitHub GraphQL scripts

These scripts might be useful if you have a private GitHub org
provisioned by University of Illinois AITS. Example scripts:

- GetOrgMemberFromSSO: Look up the GitHub username that corresponds to a
  SAML-authenticated member in your org (e.g., university email address)

- GetSSOFromOrgMember: Look up the SSO SAML identity (e.g., university
  email address) for a GitHub user who is a member of your org
